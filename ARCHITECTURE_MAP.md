# PULSIM — file / function map (v_torch/PULSIM)

Generated by AST analysis of all 61 `.py` files (root + `test/`).

The package is really **two independent stacks** that only share `mat_operator.py`:

- **A. Time-domain Bloch pulse engine** — rotates a magnetization vector through RF pulses.
- **B. Frequency-domain spin system** — builds spin Hamiltonians / peaklists / spectra (derived from `nmrsim`).

---

## B. Frequency-domain stack

### `mat.py` — peak-list & lineshape math
`add_peaks` ← `reduce_peaks`; `_normalize` ← `normalize_peaklist`; `lorentz` ← `add_lorentzians`; also `lorentzian_area_conserved`, `get_intensity`, `get_maxima`.

### `_utils.py` / `_descriptors.py`
`is_number` ← `is_tuple_of_two_numbers` ← `low_high`.
`AutoStorage` → `Validated` → `Number`, `Couplings` (descriptor validation used by `_classes`).

### `firstorder.py` — weak-coupling multiplets
`_doublet` ← `multiplet` (→ `mat.reduce_peaks`); `first_order_spin_system` → `multiplet`, `mat.reduce_peaks`.

### `spin_system.py` — quantum-mechanical second-order solver
Imports `mat_operator.spin_half`, `mat.normalize_peaklist`.

```
qm_spinsystem ─┬─ secondorder_dense  → hamiltonian_dense  → spin_system_dense
               │                     → _transition_matrix_dense → _compile_peaklist
               │                     → mat.normalize_peaklist
               └─ secondorder_sparse → hamiltonian_sparse → spin_system_sparse → _bin_path
                                     → solve_hamiltonian → _intensity_and_energy → _tm_cache
                                                         → _compile_peaklist
```

## Cross-cutting observations

1. **`mat_operator.py` is the only bridge** between the two stacks (`*_rot` → Bloch; `spin_half` → spin_system).
2. **`__init__.py` is broken**: `from rotation import Rx, Ry, Rz` — no `rotation.py` exists. It also mixes absolute (`from bloch import …`) and relative (`from ._classes import …`) imports, so `import PULSIM` fails either way. All scripts work only when run from inside the directory.
3. **Dead parallel branch**: `o_pulse.py`, `o_file_import.py`, `o_pulse_shape_list.py` are an object-oriented rewrite (`CPUImportPulse`, `CPUShapedPulse`, `XYFileReader`, `PulseShape`, `ShapedPulse`) that nothing imports.
4. **Duplicated shape-dispatch** in `pulse.py` and `bloch_pulse_simulation.py`; **duplicated fitting code** in `CS_fitting.py` / `CS_fitting_HA.py`; **duplicated `ppm_to_hz`** in 9 files.
5. `spin_system.py` imports a module named `temp` (a local directory) — fragile.
